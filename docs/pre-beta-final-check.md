# Pre-Beta Final Check

Usar antes de enviar el link a testers reales.

## 1. Contenido Founder Minimo

- [ ] Publicar 3 prompts publicos buenos.
- [ ] Crear 1 post de foro pidiendo feedback.
- [ ] Crear 1 briefing publico desde Noticias.
- [ ] Crear 1 oportunidad en Hackathons.
- [ ] Crear 1 pieza en Galeria con URL publica.

## 2. Ruta De Usuario Nuevo

- [ ] Abrir `https://biblioteca-de-prompts-ashen.vercel.app` sin login.
- [ ] Confirmar que el CTA principal es `Crear mi biblioteca`.
- [ ] Login con Google.
- [ ] Elegir pack pequeno, no pack completo.
- [ ] Ir a Prompts y guardar un remix privado.
- [ ] Abrir el remix desde Mi Biblioteca.
- [ ] Crear feedback en Foro.

## 3. Privacidad Manual

- [ ] Prompt privado no aparece en Comunidad.
- [ ] Prompt privado no aparece en perfil publico.
- [ ] Carpeta compartida no muestra prompts privados salvo publicacion explicita.
- [ ] Idea guardada no aparece para visitante.
- [ ] Briefing borrador no abre para visitante.
- [ ] Reportes no son visibles para visitantes.

## 4. Movil

- [ ] Chrome movil sin scroll horizontal.
- [ ] Safari movil sin scroll horizontal.
- [ ] WhatsApp/Instagram browser permite llegar al login o fallback.
- [ ] Modales principales caben en pantalla.
- [ ] Botones principales se pueden tocar sin zoom.

## 5. Resultado Para Invitar

Invitar solo si:

- [ ] Home carga.
- [ ] Login funciona.
- [ ] Pack inicial funciona.
- [ ] Guardar remix funciona.
- [ ] Foro permite feedback.
- [ ] No hay fugas obvias de contenido privado.
