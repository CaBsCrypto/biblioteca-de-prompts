# Contenido Fundador Para Beta

Objetivo: que la app no se sienta vacia cuando entren los primeros testers. Publicar manualmente desde la cuenta founder, revisando que cada recurso quede publico solo cuando corresponda.

## Prompts Publicos Destacados

1. **Brief creativo para video IA**
   - Categoria: YouTube
   - Objetivo: convertir una tendencia IA en un guion corto con hook, estructura y CTA.
   - Tags: `youtube`, `ia`, `guion`, `tendencias`

2. **Auditor de prompt para mejores respuestas**
   - Categoria: Asistente de Prompts
   - Objetivo: revisar un prompt y devolver mejoras de claridad, contexto, restricciones y formato.
   - Tags: `prompting`, `auditoria`, `productividad`

3. **Agente de research para hackathon**
   - Categoria: IA Agentes
   - Objetivo: ordenar problema, usuarios, benchmarks, datos y primeras hipotesis de solucion.
   - Tags: `hackathon`, `research`, `agentes`

4. **Landing rapida para recurso gratuito**
   - Categoria: Marketing
   - Objetivo: crear copy de landing para capturar emails con un lead magnet de prompts.
   - Tags: `landing`, `lead-magnet`, `copy`

5. **Post LinkedIn de aprendizaje IA**
   - Categoria: Redaccion
   - Objetivo: transformar una experiencia o noticia en un post educativo con punto de vista.
   - Tags: `linkedin`, `contenido`, `aprendizaje`

6. **Comparativa de herramientas IA**
   - Categoria: YouTube
   - Objetivo: estructurar una comparativa honesta entre herramientas con tabla, pros, contras y recomendacion.
   - Tags: `youtube`, `review`, `herramientas`

7. **Prompt para demo de producto**
   - Categoria: Marketing
   - Objetivo: convertir features en una demo clara con problema, solucion, prueba y cierre.
   - Tags: `demo`, `producto`, `ventas`

8. **Plan de sprint para builder solo**
   - Categoria: Programacion
   - Objetivo: dividir una idea en tareas tecnicas, riesgos, validaciones y entregable de 48 horas.
   - Tags: `sprint`, `builder`, `mvp`
