# Invitación para la prueba de Biblioteca

Estado: texto preparado; no enviado por agentes. El usuario confirmó que lo compartirá con 3–5 personas. No recoger correos o nombres en el registro de resultados.

## Mensaje listo para copiar

Estoy probando Biblioteca, un catálogo gratuito de prompts y skills, y quiero comprobar si resulta fácil encontrar un recurso y usarlo.

¿Te animas a una prueba de 15–20 minutos? Usaremos un ejemplo ficticio: buscar algo que ayude a explicar un fragmento de código, preparar y copiar el prompt y descargar una skill. No hace falta saber programar; sí usar habitualmente algún asistente de IA. Esa parte se puede probar como visitante.

Si quieres probar también el guardado y recuperación en tu biblioteca privada, puedes hacerlo con una cuenta de Google propia que ya tengas. No hace falta crear una cuenta ni compartirla. Si prefieres no iniciar sesión, probamos solo la parte pública.

Me interesa observar qué se entiende y dónde cuesta avanzar. No grabaremos la sesión ni pediré contraseñas, documentos de trabajo o contenido privado. Puedes saltar una tarea o terminar cuando quieras.

La web es https://biblioteca.browns.studio/. Podemos hacerlo en ordenador o móvil. Si te interesa, acordamos una hora para probarla juntos.

## Mensaje adicional para una persona creadora

Además, me gustaría que una persona interesada en compartir prompts o skills probara el proceso de aportar un recurso propio. Serían otros 25–35 minutos, aparte de la prueba común, para crear un borrador con datos ficticios, enviarlo a revisión y comprobar qué ocurre con la decisión. Yo haría la revisión como founder; tu recurso no se publicaría automáticamente.

Si prefieres usar esta extensión para explorar el proceso, podemos dejar la postulación pendiente y decidir su publicación después de revisar el contenido y las condiciones de uso.

## Preparación al concertar la sesión

- Confirmar que dispone de 15–20 minutos y de su propio asistente de IA. La sesión de creador se agenda aparte durante 25–35 minutos, con el founder disponible. Incluir una persona creadora entre P01–P03; C01 identifica su sesión de creador, no una cuarta persona. P04 y P05 son opcionales.
- Acordar la parte de biblioteca privada solo si la persona quiere utilizar una cuenta de Google propia que ya tenga; las tres primeras tareas no requieren login. No pedir creación de cuenta, cuentas prestadas o transferencia de contenido sensible.
- Pedir solo el tipo de dispositivo que usará; no solicitar credenciales ni archivos de trabajo.
- Compartir la URL pública, sin enlaces de administración o Preview protegido.
- No ofrecer instalación del plugin personal a participantes externos ni compartir otra cuenta. La prueba común es la web.
- Usar el consentimiento breve de [prueba-usuarios.md](prueba-usuarios.md) al empezar. La respuesta a la invitación no equivale a una sesión completada.

El envío de estas invitaciones y la selección de participantes quedan a cargo del founder. Los agentes preparan el material y analizan las observaciones que se registren; no se han contactado personas ni programado sesiones.
